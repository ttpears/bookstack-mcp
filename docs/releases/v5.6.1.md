# bookstack-mcp v5.6.1

This maintenance release refreshes dependencies and plugin marketplace metadata.

## Updated

- Locked MCP SDK to 1.32.1 and Zod to 4.6.7 for reproducible builds, including
  the published container image.
- Updated Node type definitions and the Node setup and HOL scanner CI actions.

## Plugin metadata

- Added the native Codex plugin manifest and shared MCP configuration.
- Added marketplace policy links and included the terms of use in the npm package.
- Enforced plugin identity and policy links in CI.

## Compatibility

- Package, Claude plugin, Codex plugin, and Gemini extension versions are
  synchronized to 5.6.1; runtime and MCPB versions derive from the package version.
- No application source changes since 5.6.0.
