# bookstack-mcp v5.7.0

This release adds page tag management and refreshes dependencies to address
known security advisories.

## Added

- `create_page` and `update_page` accept tag arrays, including tag-only updates
  that preserve HTML and Markdown content.
- Documented tag replacement for books and pages: omitted tags remain unchanged,
  `[]` clears the list, and a supplied list replaces all existing tags.

## Security

- Updated the Docker builder and runtime from Node 20 to the supported Node 24
  LTS image, including current runtime security fixes.
- Updated MCP SDK to 1.32.2, Axios to 1.21.0, and jose to 6.2.14.
- Refreshed transitive dependencies including Express, body-parser, Hono and its
  Node adapter, AJV, fast-uri, follow-redirects, ip-address, picomatch, and qs.
  Full and production-only npm audits reported zero vulnerabilities after the
  update, down from 9 affected packages (6 high and 3 moderate) in the full audit.
- Added weekly Dependabot checks for Docker base-image updates.

## Compatibility and validation

- Package, Claude plugin, Codex plugin, and Gemini extension versions are
  synchronized to 5.7.0; runtime and MCPB versions derive from the package version.
- Plugin validation now also checks the Claude and Gemini versions.
- All 44 tests, type-checking, build, plugin validation, and the MCPB bundle
  startup check passed with the updated dependencies.
