# bookstack-mcp v5.6.0

This release adds stored HTML reads so page edits can preserve content that
BookStack's rendered view changes or removes.

## Added

- `get_page` accepts `format: "raw"` to return BookStack's stored `raw_html`,
  including unresolved page includes and attributes omitted from rendered HTML.
  The format supports the existing `offset`/`limit` pagination and returns only
  the requested content slice.

## Editing guidance

- For HTML (WYSIWYG) pages, read `format: "raw"` and write the edited HTML through
  `update_page.html`.
- For Markdown-authored pages, read `format: "markdown"` and write through
  `update_page.markdown`. Sending HTML clears the stored Markdown source.
- Choose the edit format using the page's `editor` field, which remains present
  in the `get_page` response.

## Compatibility

- The default remains Markdown. Existing `markdown`, `html`, and `text` formats
  retain their behavior.
- Package, Claude plugin, and Gemini extension versions are synchronized to
  5.6.0; runtime and MCPB versions derive from the package version.
